## 1. Bivariate & Multivariate Normal Distribution

### 1.1 Standard Normal Vector
If $Z_1, \dots, Z_d \stackrel{\text{i.i.d.}}{\sim} \mathcal{N}(0, 1)$, then $Z = [Z_1, \dots, Z_d]^T \sim \mathcal{N}(\mathbf{0}, I_d)$ has joint PDF:
$$f_Z(z) = \frac{1}{(2\pi)^{d/2}} \exp\left(-\frac{1}{2}\|z\|_2^2\right)$$

### 1.2 General Multivariate Normal: $X \sim \mathcal{N}(\mu, \Sigma)$
Any Multivariate Normal vector $X \in \mathbb{R}^d$ can be constructed as an affine transformation $X = A Z + \mu$ where $Z \sim \mathcal{N}(\mathbf{0}, I_d)$, $\mu = \mathbb{E}[X]$, and $\Sigma = A A^T$ is the **Covariance Matrix** (which is symmetric and positive semi-definite):
$$\Sigma_{ij} = \text{Cov}(X_i, X_j)$$
When $\Sigma$ is positive definite (invertible), the PDF is:
$$f_X(x) = \frac{1}{(2\pi)^{d/2} |\Sigma|^{1/2}} \exp\left(-\frac{1}{2}(x - \mu)^T \Sigma^{-1} (x - \mu)\right)$$

### 1.3 Key Properties
1. **Linear Transformations Remain Normal:** If $X \sim \mathcal{N}(\mu, \Sigma)$ and $Y = C X + b$ (for matrix $C$ and vector $b$):
   $$Y \sim \mathcal{N}\big(C\mu + b, \; C \Sigma C^T\big)$$
   * *Tutorial Example:* If $Y \sim \mathcal{N}_3(\mu, \Sigma)$ and $Z = c^T Y = 2y_1 - y_2 + 3y_3$ with $c = [2, -1, 3]$, then $\mathbb{E}[Z] = c^T\mu$ and $\text{Var}(Z) = c^T \Sigma c$.
2. **Uncorrelated $\iff$ Independent (for Jointly Normal RVs):**  
   For general RVs, independence $\implies$ zero covariance, but the converse is false. For **jointly Gaussian** RVs, $\text{Cov}(X_i, X_j) = 0$ ($\Sigma$ is diagonal) **if and only if** $X_1, \dots, X_d$ are independent!

## 2. Maximum Likelihood Estimation (MLE)

Given i.i.d. data $\mathcal{D} = \{x_1, \dots, x_n\}$ drawn from a parameterized family $P_\theta$, how do we estimate the true parameter $\theta$?
* **Likelihood Function:** $\mathcal{L}(\theta) = \prod_{i=1}^n P_\theta(x_i)$
* **Log-Likelihood Function** (monotonically increasing transform, turns products into sums):
  $$\ell(\theta) = \log \mathcal{L}(\theta) = \sum_{i=1}^n \log P_\theta(x_i)$$
* **MLE Objective:** $\hat{\theta}_{\text{MLE}} = \arg\max_\theta \ell(\theta)$.

### Classic MLE Results

1. **Bernoulli($\theta$)** ($x_i \in \{0, 1\}$):
   $$\ell(\theta) = \sum_{i=1}^n \big[x_i \log\theta + (1 - x_i)\log(1 - \theta)\big] \implies \frac{d\ell}{d\theta} = 0 \implies \hat{\theta}_{\text{MLE}} = \frac{1}{n}\sum_{i=1}^n x_i = \bar{x}$$
2. **Uniform($a, b$):**
   $$\mathcal{L}(a, b) = \begin{cases} \frac{1}{(b - a)^n} & \text{if } a \le \min_i x_i \text{ and } \max_i x_i \le b \\ 0 & \text{otherwise} \end{cases}$$
   To maximize $\frac{1}{(b-a)^n}$, make $(b-a)$ as small as possible while containing all data:
   $$\hat{a}_{\text{MLE}} = \min_i x_i, \qquad \hat{b}_{\text{MLE}} = \max_i x_i$$
3. **Univariate Normal $\mathcal{N}(\mu, \sigma^2)$:**
   $$\hat{\mu}_{\text{MLE}} = \frac{1}{n}\sum_{i=1}^n x_i = \bar{x}, \qquad \hat{\sigma}^2_{\text{MLE}} = \frac{1}{n}\sum_{i=1}^n (x_i - \bar{x})^2$$
   *(If $\mu$ is known, $\hat{\sigma}^2_{\text{MLE}} = \frac{1}{n}\sum_{i=1}^n (x_i - \mu)^2$.)*
4. **Multivariate Normal $\mathcal{N}(\mu, \Sigma)$:**
   $$\hat{\mu}_{\text{MLE}} = \frac{1}{n}\sum_{i=1}^n x_i, \qquad \hat{\Sigma}_{\text{MLE}} = \frac{1}{n}\sum_{i=1}^n (x_i - \hat{\mu})(x_i - \hat{\mu})^T$$
5. **Linear Regression with Gaussian Noise:**  
   Assume $y_i = w^T x_i + \epsilon_i$ where $\epsilon_i \stackrel{\text{i.i.d.}}{\sim} \mathcal{N}(0, \sigma^2)$, so $y_i \mid x_i \sim \mathcal{N}(w^T x_i, \sigma^2)$.
   $$\ell(w) = -\frac{1}{2\sigma^2}\sum_{i=1}^n (y_i - w^T x_i)^2 + \text{const}$$
   **Maximizing log-likelihood $\equiv$ Minimizing Least Squares Error!**

## 3. Gaussian Mixture Models (GMM) & Expectation-Maximization (EM)

### 3.1 The Generative Model
Suppose data comes from $K$ clusters. Each point $x_n$ is generated by:
1. Sampling a latent cluster assignment $Z_n \in \{1, \dots, K\}$ with probability $P(Z_n = k) = \pi_k$ ($\sum_{k=1}^K \pi_k = 1$).
2. Sampling $X_n \mid (Z_n = k) \sim \mathcal{N}(\mu_k, \Sigma_k)$.

Marginal density of $x$:
$$P(x) = \sum_{k=1}^K \pi_k \, \mathcal{N}(x \mid \mu_k, \Sigma_k)$$

### 3.2 The Chicken-and-Egg Problem & The EM Algorithm
Maximizing $\sum_{n=1}^N \log \left(\sum_{k=1}^K \pi_k \mathcal{N}(x_n \mid \mu_k, \Sigma_k)\right)$ directly has no closed-form solution because the $\log$ traps a sum inside.
* If we knew which cluster generated each point, we could easily compute $\pi_k, \mu_k, \Sigma_k$.
* If we knew $\pi_k, \mu_k, \Sigma_k$, we could compute which cluster each point belongs to.

**Expectation-Maximization (EM)** alternates between the two:
1. **E-Step (Compute Cluster Responsibilities):** Using current parameters, compute the posterior probability that point $n$ belongs to cluster $k$:
   $$\gamma_{nk} = P(Z_n = k \mid X_n = x_n) = \frac{\pi_k \, \mathcal{N}(x_n \mid \mu_k, \Sigma_k)}{\sum_{j=1}^K \pi_j \, \mathcal{N}(x_n \mid \mu_j, \Sigma_j)}$$
2. **M-Step (Update Parameters):** Let $N_k = \sum_{n=1}^N \gamma_{nk}$ be the effective number of points in cluster $k$:
   $$\pi_k^{\text{new}} = \frac{N_k}{N}, \qquad \mu_k^{\text{new}} = \frac{1}{N_k} \sum_{n=1}^N \gamma_{nk} x_n, \qquad \Sigma_k^{\text{new}} = \frac{1}{N_k} \sum_{n=1}^N \gamma_{nk} (x_n - \mu_k^{\text{new}})(x_n - \mu_k^{\text{new}})^T$$

## 4. Concentration Inequalities

Concentration inequalities bound how likely a random variable is to deviate far from its mean, even when we don't know its exact distribution!

### 4.1 Markov's Inequality
For any **non-negative** random variable $X \ge 0$ and any $t > 0$:
$$P(X \ge t) \le \frac{\mathbb{E}[X]}{t}$$
* **Proof:** $\mathbb{E}[X] = \int_0^\infty x f(x)\,dx \ge \int_t^\infty x f(x)\,dx \ge t \int_t^\infty f(x)\,dx = t \, P(X \ge t)$. $\blacksquare$
* *Tutorial Example:* For $X \sim \text{Bin}(n, p)$ with $p = \frac{1}{3}, \alpha = \frac{3}{4}$: $P(X \ge \alpha n) \le \frac{np}{\alpha n} = \frac{p}{\alpha} = \frac{1/3}{3/4} = \frac{4}{9}$ (or check exact numbers per problem).

### 4.2 Chebyshev's Inequality
For any random variable $X$ with mean $\mu = \mathbb{E}[X]$ and finite variance $\sigma^2 = \text{Var}(X)$, and any $t > 0$:
$$P\big(|X - \mu| \ge t\big) \le \frac{\text{Var}(X)}{t^2} = \frac{\sigma^2}{t^2}$$
* **Proof:** Apply Markov's inequality to the non-negative RV $Y = (X - \mu)^2$ with threshold $t^2$:
  $$P(|X - \mu| \ge t) = P\big((X - \mu)^2 \ge t^2\big) \le \frac{\mathbb{E}[(X - \mu)^2]}{t^2} = \frac{\text{Var}(X)}{t^2}$$

### 4.3 Hoeffding's Inequality (Exponentially Tighter for Averages!)
Let $X_1, \dots, X_n$ be **i.i.d.** random variables with mean $\mu$, bounded in $[a, b]$ ($a \le X_i \le b$). Let $\bar{X}_n = \frac{1}{n}\sum_{i=1}^n X_i$. Then for any $\epsilon > 0$:
$$P\big(|\bar{X}_n - \mu| \ge \epsilon\big) \le 2 \exp\left(-\frac{2 n \epsilon^2}{(b - a)^2}\right)$$
* **Why is this huge in ML?** Chebyshev decays like $\mathcal{O}(1/n)$ for sample averages, whereas Hoeffding decays **exponentially fast** in $n$! This underpins generalization bounds in Statistical Learning Theory.

## 5. Laws of Large Numbers & Central Limit Theorem

### 5.1 Modes of Convergence
* **Convergence in Probability ($X_n \xrightarrow{p} X$):** $\lim_{n \to \infty} P(|X_n - X| \ge \epsilon) = 0$ for all $\epsilon > 0$.
* **Convergence in Distribution ($X_n \xrightarrow{d} X$):** $\lim_{n \to \infty} F_{X_n}(x) = F_X(x)$ at all continuity points of $F_X$.

### 5.2 Weak Law of Large Numbers (WLLN)
Let $X_1, \dots, X_n$ be i.i.d. with mean $\mu$ and finite variance $\sigma^2$. Let $\bar{X}_n = \frac{1}{n}\sum_{i=1}^n X_i$.  
Since $\mathbb{E}[\bar{X}_n] = \mu$ and $\text{Var}(\bar{X}_n) = \frac{\sigma^2}{n}$, Chebyshev's inequality gives:
$$P(|\bar{X}_n - \mu| \ge \epsilon) \le \frac{\sigma^2}{n \epsilon^2} \xrightarrow{n \to \infty} 0$$
Thus, **the sample mean converges in probability to the true mean:** $\bar{X}_n \xrightarrow{p} \mu$.

### 5.3 Central Limit Theorem (CLT)
Even if $X_i$ are **not** Gaussian (as long as they are i.i.d. with finite mean $\mu$ and variance $\sigma^2$), the properly scaled average converges in distribution to a Normal distribution!
$$Y_n = \sqrt{n}\big(\bar{X}_n - \mu\big) = \frac{1}{\sqrt{n}}\sum_{i=1}^n (X_i - \mu) \xrightarrow{d} \mathcal{N}(0, \sigma^2)$$
Equivalently, $\frac{\sqrt{n}(\bar{X}_n - \mu)}{\sigma} \xrightarrow{d} \mathcal{N}(0, 1)$.
