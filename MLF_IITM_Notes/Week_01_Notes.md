## 1. What is Machine Learning?

### Formal Definition
**Machine Learning (ML)** is the study of computer algorithms that improve automatically through experience and by the use of data.

### The Task Hierarchy (Evolution of Problem Solving)
To understand *why* we need ML, consider how humans solve tasks at increasing levels of complexity:

| Level | Paradigm | How it works |
| :--- | :--- | :--- |
| 1 | **Manual Labour** | Human directly takes Input $\to$ produces Output. |
| 2 | **Tool Usage** | Human designs a physical tool; Human uses tool on Input $\to$ Output. |
| 3 | **Programming** | Human designs software (explicit rules); Software takes Input $\to$ Output. |
| 4 | **Machine Learning** | Human designs a **Learning Algorithm**; Algorithm takes **Data** $\to$ produces a **Model**; Model takes Input $\to$ Output. |

### Why and When Do We Use Machine Learning?
ML is **not** needed for every problem. Traditional programming works great when you know the exact rules!

**When traditional programming / manual labour fails:**
1. **Scale / Speed / Cost:** Too expensive or slow for humans to do manually.
2. **Inability to express rules in code:** Humans can do the task intuitively (e.g., recognizing a face), but cannot write explicit `if-else` rules for pixels.
3. **Unknown rules:** We don't even know the exact mathematical rules transforming input to output (e.g., weather prediction from radar maps).

**When ML succeeds:**
1. We have **lots of example data**.
2. We have **some structural idea** about the rules (a family of candidate models).

#### Case Studies from Lecture:
* **Password Verification:** Manual labour fails (scale), but programming succeeds easily (`stored_hash == input_hash`). $\implies$ **ML NOT required.**
* **Face Detection / Tagging:** Manual labour fails (scale), programming fails (cannot write pixel rules for "what is a face"). Lots of tagged images exist. $\implies$ **ML required.**
* **Weather Prediction:** Manual labour fails (humans can't process massive radar data or know exact physics at scale), programming fails (rules unknown). Lots of historical weather data exists. $\implies$ **ML required.**

## 2. Data, Models, and Learning Algorithms

### What is Data?
* **Data** is a collection of vectors (points in a multi-dimensional space).
* **Metadata** is information *about* the data (what each coordinate/feature represents).

*Example (House Pricing):*  
Metadata: $(\text{\# rooms}, \text{Area in } 100\text{ sq.ft}, \text{Distance to metro in km}, \text{Price in } 10\text{ lakhs})$  
A single house is a vector, e.g., $x = [3, 9, 1.9, 5.0]^T$.

### What is a Model?
> *"All models are wrong, but some are useful."* — George Box

A **model** is a mathematical simplification of reality. Examples in science include the Ideal Gas Law ($PV = nRT$), Newton's Inverse Square Law, and Moore's Law.

In ML, we mainly encounter two broad categories of models:
1. **Predictive Models:** Predict an output from an input.
   * *Regression Model:* Predicts a continuous number (e.g., $\text{Price} = 0.5 \times \text{Area} - \text{Distance}$).
   * *Classification Model:* Predicts a discrete category/label (e.g., `Close` if $2 \times \text{Rooms} - \text{Price} < 1$, else `Far`).
2. **Probabilistic Models:** Assign probabilities to events or data points (e.g., *"What is the probability that a given tweet was generated by Mr. X?"*).

### What is a Learning Algorithm?
$$\text{Learning Algorithm: } \text{Data} \longrightarrow \text{Model}$$

A learning algorithm chooses the "best" model from a **collection of models** (which share the same mathematical structure, but have different **parameters**).

*Example:*  
Model structure: $\text{Price} = a \cdot (\text{area}) + b \cdot (\text{\# rooms}) + c \cdot (\text{distance to metro})$  
Here, $a, b, c$ are **parameters**. The learning algorithm uses training data to find the optimal values of $a, b, c$.

## 3. Essential Mathematical Notation

Throughout the course, we use standard notation:
* $\mathbb{R}$: Set of all real numbers.
* $\mathbb{R}_+$: Set of positive real numbers.
* $\mathbb{R}^d$: Set of $d$-dimensional real vectors.
* $x \in \mathbb{R}^d$: A vector; $x_j$ denotes its $j$-th coordinate.
* $\|x\|$: Euclidean length (norm) of vector $x$.
* $x_1, x_2, \dots, x_n$: A collection of $n$ data vectors.
* $x_i^j$ (or $(x_i)_j$): The $j$-th coordinate of the $i$-th vector.
* $(x_1)^2$: Square of the 1st coordinate of vector $x$.
* **Indicator Function $\mathbf{1}(\text{condition})$:** Evaluates to $1$ if the condition is true, and $0$ if false.
  * Example: $\mathbf{1}(2 \text{ is even}) = 1$, and $\mathbf{1}(2 \text{ is odd}) = 0$.

## 4. Supervised Learning

**Core Idea:** Supervised learning is **curve-fitting**. We are given both inputs and their desired outputs (labels).

* **Training Data:** $\{(x_1, y_1), (x_2, y_2), \dots, (x_n, y_n)\}$
* **Goal:** Find a function (model) $f$ such that $f(x_i)$ is "close" to $y_i$ for all training examples (and generalizes well to unseen examples).

### 4.1 Regression
Used when the target output $y_i$ is a **continuous real number**.
* **Setup:** $x_i \in \mathbb{R}^d$, $y_i \in \mathbb{R}$.
* **Model:** $f : \mathbb{R}^d \to \mathbb{R}$.
* **Common Model Structure (Linear Parameterization):**
  $$f(x) = w^T x + b = \sum_{j=1}^d w_j x_j + b$$
  where $w \in \mathbb{R}^d$ is the weight vector and $b \in \mathbb{R}$ is the bias (intercept).
* **Loss Function (Mean Squared Error / Squared Loss):**
  $$\text{Loss}(f) = \frac{1}{n} \sum_{i=1}^n \big(f(x_i) - y_i\big)^2$$
  The learning algorithm searches for parameters $(w, b)$ that **minimize** this loss.

### 4.2 Classification
Used when the target output $y_i$ is a **discrete category/class** (in binary classification, typically $+1$ or $-1$).
* **Setup:** $x_i \in \mathbb{R}^d$, $y_i \in \{+1, -1\}$.
* **Model:** $f : \mathbb{R}^d \to \{+1, -1\}$.
* **Common Model Structure (Linear Separator):**
  $$f(x) = \text{sign}(w^T x + b)$$
  where $\text{sign}(z) = +1$ if $z \ge 0$ and $-1$ if $z < 0$. Geometrically, $w^T x + b = 0$ defines a hyperplane separating the two classes.
* **Loss Function (0-1 Loss / Misclassification Rate):**
  $$\text{Loss}(f) = \frac{1}{n} \sum_{i=1}^n \mathbf{1}\big(f(x_i) \neq y_i\big)$$
  This measures the **fraction of training data classified wrongly** by $f$.

## 5. Evaluating Models & Model Selection

### Why Not Evaluate on Training Data?
If we evaluate a learned model on the **same data** it was trained on, a complex model can simply memorize the training points (achieving $0$ training loss) while performing terribly on new inputs! This is called **overfitting**.

### The Three-Way Data Split
1. **Training Data:** Used by the learning algorithm to find the best parameters within a chosen model family.
2. **Validation Data:** Distinct from train and test data. Used for **Model Selection** — choosing *which* model family/structure or hyperparameters to use (e.g., linear vs. polynomial of degree 3).
3. **Test Data:** Distinct from both train and validation data. Held out until the very end to give an **unbiased evaluation** of how well the final model performs on unseen real-world data.

## 6. Unsupervised Learning

**Core Idea:** Unsupervised learning is **"understanding data"** when there are **no target labels $y_i$**.
* **Data:** $\{x_1, x_2, \dots, x_n\}$ where $x_i \in \mathbb{R}^d$.
* **Goal:** Build models that **compress, explain, or group** data.

### 6.1 Dimensionality Reduction
Represent high-dimensional data in a much lower-dimensional space while preserving as much information as possible (compression & simplification).
* *Example:* Representing $1{,}000{,}000$ gene expression levels of a person using just $100$ numbers ($10^6 \to 100$).
* **Mathematical Formulation:**
  * **Encoder:** $f : \mathbb{R}^d \to \mathbb{R}^{d'}$ (where $d' \ll d$)
  * **Decoder:** $g : \mathbb{R}^{d'} \to \mathbb{R}^d$
  * **Goal:** Reconstruct the original input after compression: $g(f(x_i)) \approx x_i$.
  * **Loss Function (Reconstruction Loss):**
    $$\text{Loss}(f, g) = \frac{1}{n} \sum_{i=1}^n \|g(f(x_i)) - x_i\|^2$$

### 6.2 Density Estimation
Learn a probability distribution over the input space so that likely (real) data points get high probability and unlikely points get low probability.
* *Example:* Modeling tweets from an account to assign a probability score to any 128-character string, enabling us to generate realistic-looking new tweets (or detect anomalies).
* **Mathematical Formulation:**
  * **Model:** A probability mapping $P : \mathbb{R}^d \to \mathbb{R}_+$ that sums (discrete) or integrates (continuous) to $1$.
  * **Goal:** $P(x)$ should be large if $x$ comes from the data distribution, and small otherwise.
  * **Loss Function (Negative Log-Likelihood):**
    $$\text{Loss}(P) = \frac{1}{n} \sum_{i=1}^n -\log P(x_i)$$
  * *Why $-\log$?* If $P(x_i)$ is close to $1$ (good), $-\log P(x_i)$ is close to $0$ (low loss). If $P(x_i)$ is close to $0$ (bad), $-\log P(x_i) \to +\infty$ (huge penalty).
  * *Examples of Density Models:* Uniform distributions, **Gaussian Mixture Models (GMMs)** (which naturally connect to **clustering**).

## 7. Quick Summary Table

| ML Paradigm | Data Given | Model Output | Typical Loss Function |
| :--- | :--- | :--- | :--- |
| **Regression** (Supervised) | $\{(x_i, y_i)\},\ y_i \in \mathbb{R}$ | $f(x) \in \mathbb{R}$ | $\frac{1}{n}\sum (f(x_i) - y_i)^2$ |
| **Classification** (Supervised) | $\{(x_i, y_i)\},\ y_i \in \{+1, -1\}$ | $f(x) \in \{+1, -1\}$ | $\frac{1}{n}\sum \mathbf{1}(f(x_i) \neq y_i)$ |
| **Dimensionality Reduction** (Unsupervised) | $\{x_i\},\ x_i \in \mathbb{R}^d$ | $f(x) \in \mathbb{R}^{d'}$ ($d' < d$) | $\frac{1}{n}\sum \|g(f(x_i)) - x_i\|^2$ |
| **Density Estimation** (Unsupervised) | $\{x_i\},\ x_i \in \mathbb{R}^d$ | $P(x) \in \mathbb{R}_+$ ($\sum P = 1$) | $\frac{1}{n}\sum -\log P(x_i)$ |
