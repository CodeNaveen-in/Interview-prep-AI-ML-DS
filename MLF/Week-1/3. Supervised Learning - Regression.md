# Notation
- Reals
	- $\mathbb{R}$ : Real Numbers
	- $\mathbb{R}_+$ : Positive reals
	- $\mathbb{R}^d$ : d-dimensional vectors of reals
- Vector
	- $x$ : vector
	- $x_j$ : $j^{\text{th}}$ co-ordinate.
	- $||x||$ : Length of vector $x$
- $x^1, x^2, ......, x^n$ : Collection of $n$ vectors
- $x^i_j$: $j^{\text{th}}$ co-ordinate of $i^{\text{th}}$ vector
- $(x_1)^2$ : Sqaure of the first co-ordinate of the vector $x$.
- $1$ (2 is even) = 1, $1$(2 is odd) = 0
# Supervised Learning
- Supervised Learning is curve-fitting.
- Given {$(x^1, y^1), (x^2, y^2), ......, (x^n, y^n)$}
- Find a model $f$ such that $f(x^i)$ is 'close' to $y^i$
## Regression
- Predict house price from room, area, distance.
- **Training data** : { $(x^1, y^1), (x^2, y^2), ...., (x^n, y^n)$ }
- $x^i \in \mathbb{R}^d, y^i \in \mathbb{R}$
- Algorithm outputs a model : $f: \mathbb{R^d} \to \mathbb{R}$
- Loss $f$ = $\frac{1}{n} \sum^{n}_{i=1} (f(x^i)-y^i)^2$
- Linear Parameterization : $f(x) = w^Tx + b = \sum^{d}_{j=1} w_jx_j + b$
