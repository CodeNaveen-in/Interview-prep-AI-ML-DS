# Geometry of Lines
1. A line in $\mathbb{R}^d \subset \mathbb{R}^d$
2. A line through the point $u \in \mathbb{R}^d$ along the vector $v \in \mathbb{R}^d$
	1. ${ x \in \mathbb{R}^d : x = u + \alpha v \text{ for } \alpha \in \mathbb{R}}$
	2. Line through $u, u' \in \mathbb{R}^d$
		1. $= {x \in \mathbb{R}^d : x = u+ \alpha(u'-u) \text{ for } \alpha \in \mathbb{R}}$
		2. $= {x \in \mathbb{R}^d : x = (1 - \alpha) u + \alpha u' \text{ for } \alpha \in \mathbb{R}}$
		3. Line through $u$ along $u' -u$
		4. Line through $u$ along $u -u'$
# Geometry of (Hyper)planes
- A $(d-1)$ dimensional hyperplane $\subset \mathbb{R}^d$
- A hyperplane normal to the vector $W \in \mathbb{R}^d$ with value $b \in \mathbb{R}$
	- $=\{ x \in \mathbb{R}^d : W^Tx = b\}$
	- $= \{x \in \mathbb{R}^d : \sum^{d}_{i=1} w_i x_i = b\}$

# Partial Derivatives
- $f : \mathbb{R}^2 \to \mathbb{R}$
	- $f(x_1, x_2) = x_1^2 + x_2^2$
- $\frac{\sigma f}{\sigma x_1}(v) = \lim_{\alpha \to 0} \frac{f(v+ \begin{bmatrix} \alpha \\ 0 \end{bmatrix}) - f(v)}{\alpha}$
- $\frac{\sigma f}{\sigma x_1}(v) = \lim_{\alpha \to 0} \frac{f(v_1 + \alpha, v_2) - f(v_1, v_2)}{\alpha}$
- $\frac{\sigma f}{\sigma x_1}(v) = \lim_{\alpha \to 0} \frac{f(v+ \alpha e_i) - f(v)}{\alpha}$
# Gradients
$$ f: \mathbb{R}^d \to \mathbb{R}$$
$$ \frac{\partial f}{\partial x} (v) = \left[\frac{\partial f}{\partial x_1} (v), \frac{\partial f}{\partial x_2} (v), \dots ,\frac{\partial f}{\partial x_d} (v)\right]$$
$$\nabla f(v) = \left[\frac{\partial f}{\partial x}\right]^T$$
