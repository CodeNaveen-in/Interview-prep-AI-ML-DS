# Continuity of Functions
$$ f: \mathbb{R} \to \mathbb{R}$$
is continuous at $x^* \in \mathbb{R}$ if for all sequences $x_1, x_2, x_3, \dots$ converging to $x^*$ we have that $f(x_i)$ converges to $f(x^*)$

$$ \lim_{i \to \infty} x_i = x^* => \lim_{i \to \infty} f(x_1) = f(x^x)$$
$$ \lim{x \to x^*} f(x) = f(x^*)$$
- Example 1 : $f(x) = x^2, x^* = 2$
	- $x_i : 3, 2.5, 2.25, \dots => 2$
	- $f(x_i) : 9, 6.25, (2.25)^2, \dots => 4$
- Example 2 : $f(x) = sign(x) = {}\begin{cases} -1 & \text{if } x < 0 \\ +1 & \text{if } x = 0 \\ +1 & \text{if } x > 0 \end{cases}$
	- $x^* = 0$
	- $x_1 : 1, \frac{1}{2}, \frac{1}{4}, \dots \to 0$
	- $f(x_1) : 1, 1, 1, \dots \to 1$
	- $x_i : -1, \frac{-1}{2}, \frac{-1}{4}, \dots \to 0$
	- $f(x_i) : -1, -1, -1, \dots \to -1$
- Example 3 : $f(x) = \begin{cases} 2x+1 & \text{if } x>1 \\ 3 & \text{if } x \leq 1 \end{cases}$
	- $f(x) = \frac{1}{x}$
	- $x_i : 1, \frac{1}{2}, \frac{1}{4}, \dots$
	- $f(x_i) : 1, 2, 4, 8$
# Differentiability of Functions
- A function $f: \mathbb{R} \to \mathbb{R}$ is differentiable at $x^* \in \mathbb{R}$ if $\lim_{x \to x^*} \frac{f(x) - f(x^*)}{x-x^*}$ exists.
- $f$ is NOT continuous at $x^* => f$ is NOT differentiable at $x^*$
- **Example 1** : $f(x) : |x|$
	- $x_i : 1, \frac{1}{2}, \frac{1}{4}, \dots \to 0$
	- $\frac{f(x_i) - f(0)}{x_i} : 1,1,1 \to 1$
- **Example 2** : $f(x) = \begin{cases} 4x+2 & \text{if} x \geq 2 \\ 2x+8 & \text{if} x > 2\end{cases}$
- **Example 3** : $f(x) = \begin{cases} 4x+2 & \text{if} x \geq 2 \\ 2x+6 & \text{if} x > 2\end{cases}$
